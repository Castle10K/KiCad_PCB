# 2S 배터리용 전원 분배 PCB 설계 정리

## 1. 목적

2S Li-ion/LiPo 배터리의 `VBAT` 전원, 약 7.4V nominal / 8.4V full charge를 받아서 아래 부하로 분배하는 소형 전원 분배 PCB를 만든다.

```text
2S 배터리 VBAT
  ├─ 모터 드라이버 / 모터 전원
  ├─ 5V 벅컨버터 입력
  ├─ 3.3V 벅컨버터 입력
  └─ 예비 출력 1개
```

핵심 목표는 만능기판에서 전원선을 일일이 자르고 납땜하는 작업을 줄이고, 커넥터만 납땜하면 안정적으로 전원이 분배되도록 하는 것이다.

---

## 2. 권장 회로 구조

기본 구조는 다음과 같다.

```text
BATT_IN
  ↓
Fuse / PTC
  ↓
Reverse Protection
  ↓
Power LED
  ↓
Power Distribution
  ├─ MOTOR_OUT
  ├─ BUCK_5V_IN
  ├─ BUCK_3V3_IN
  └─ SPARE_OUT
```

### 네트 이름 추천

| 용도 | 추천 네트명 |
|---|---|
| 배터리 + | `VBAT` |
| 배터리 - / 공통 GND | `GND` |
| 모터 전원 + | `VBAT`와 동일 네트 |
| 모터 전원 - | `GND`와 동일 네트 |
| 5V 컨버터 입력 + | `VBAT`와 동일 네트 |
| 5V 컨버터 입력 - | `GND`와 동일 네트 |
| 3.3V 컨버터 입력 + | `VBAT`와 동일 네트 |
| 3.3V 컨버터 입력 - | `GND`와 동일 네트 |

출력마다 별도 네트명을 만들기보다, 같은 전원 분배 목적이면 `VBAT`와 `GND`로 통일하는 것이 단순하다.

| 전원 LED | 1 | 0805 LED / 3mm LED | 전원 인가 표시 | 없어도 되지만 추천 |

| 테스트포인트 | 2 | TP_VBAT, TP_GND | 전압 측정용 | 멀티미터 찍기 편함 |

| 구분 | 수량 | 예시 부품 | 역할 | 비고 |
|---|---:|---|---|---|

| 입력 세라믹 캐패시터 | 1 | 0.1uF / 1uF MLCC | 고주파 노이즈 우회 | 전원 입력 근처 배치 |
| 마운팅 홀 | 2~4 | M2.5 / M3 | 보드 고정 | 주변 구리 keepout 추천 |

## 4. 풋프린트 추천

### 스크류 터미널

| 용도 | 추천 풋프린트 | 비고 |
|---|---|---|
| 배터리 입력 | `TerminalBlock_1x02_P5.08mm` 계열 | KF301 2P 5.08mm류와 유사 |
| 모터 출력 | `TerminalBlock_1x02_P5.08mm` 계열 | 전류가 크므로 5.08mm 권장 |
| 컨버터 입력 | `TerminalBlock_1x02_P5.08mm` 또는 JST-VH | 탈착성과 전류 여유 고려 |
| 예비 출력 | `TerminalBlock_1x02_P5.08mm` | 통일하면 조립이 편함 |

KiCad 기본 라이브러리에서는 보통 아래 계열에서 찾는다.

```text
TerminalBlock
TerminalBlock_Phoenix
TerminalBlock_bornier
Connector_JST
Connector_Wire
```

실제 구매한 커넥터와 풋프린트의 핀 간격, 구멍 크기, 외형 크기를 반드시 대조해야 한다.

### PTC / 퓨즈

| 형태 | 추천 풋프린트 | 비고 |
|---|---|---|
| 리드형 PTC | `Fuse:Fuse_Blade`보다는 실제 리드 간격에 맞는 THT 풋프린트 | 구매품 치수 확인 필요 |
| SMD PTC | 1206 / 1812 / 2920 계열 | 전류가 클수록 큰 패키지 필요 |
| 일반 퓨즈 홀더 | 제품별 전용 풋프린트 | 크기가 커질 수 있음 |

프로토타입이면 리드형 PTC나 인라인 퓨즈도 현실적이다.

### 역극성 보호 다이오드

| 형태 | 추천 풋프린트 | 비고 |
|---|---|---|
| THT 쇼트키 | `Diode_THT` 계열 | 납땜 쉬움, 발열 확인 쉬움 |
| SMD 쇼트키 | SMA / SMB / SMC | 전류가 커질수록 패키지 키우기 |

다이오드는 전류가 흐르면 전압강하가 생기고 발열도 난다. 모터 전류가 큰 경우에는 다이오드 방식보다 MOSFET 역극성 보호가 더 좋을 수 있다.

### LED / 저항

| 부품 | 추천 풋프린트 | 비고 |
|---|---|---|
| 전원 LED | `LED_SMD:LED_0805_2012Metric` | 손납땜 가능 |
| LED 저항 | `Resistor_SMD:R_0805_2012Metric` | 1kΩ ~ 2.2kΩ 권장 |

2S 배터리 최대 8.4V 기준으로 LED 저항은 아래처럼 대략 잡을 수 있다.

```text
빨간 LED Vf 약 2V, 목표 전류 약 3~5mA
R = (8.4V - 2V) / 0.003~0.005A
  ≈ 1.3kΩ ~ 2.1kΩ
```

따라서 `1.5kΩ`, `2.2kΩ` 정도가 무난하다. 너무 밝을 필요가 없으면 2.2kΩ 추천.

### 캐패시터

| 부품 | 추천 풋프린트 | 비고 |
|---|---|---|
| 470uF 전해 캐패시터 | `Capacitor_THT:CP_Radial_D...` 계열 | 실제 리드 간격과 지름 확인 |
| 0.1uF 세라믹 | `Capacitor_SMD:C_0805_2012Metric` | 입력 커넥터 근처 배치 |
| 1uF 세라믹 | `Capacitor_SMD:C_0805_2012Metric` | 선택 |

전해 캐패시터는 극성이 있으므로 PCB 실크에 `+` 표시를 크게 넣는 것이 좋다.

### 테스트포인트

| 용도 | 추천 풋프린트 | 비고 |
|---|---|---|
| TP_VBAT | `TestPoint:TestPoint_Pad_D2.0mm` 등 | 빨간 프로브용 |
| TP_GND | `TestPoint:TestPoint_Pad_D2.0mm` 등 | 검은 프로브용 |

테스트포인트는 서로 너무 가깝게 두지 말고, 실크로 `VBAT`, `GND`를 크게 표시한다.

### 마운팅 홀

| 용도 | 추천 풋프린트 | 비고 |
|---|---|---|
| M3 고정 | `MountingHole:MountingHole_3.2mm_M3` | 주변 구리 제거 추천 |
| M2.5 고정 | `MountingHole:MountingHole_2.7mm_M2.5` | 작은 보드에 적합 |

마운팅 홀 주변은 구리영역이 닿지 않게 keepout을 둔다. 금속 나사와 스페이서가 전원층에 닿는 것을 방지하기 위해서다.

## 5. PCB 레이어 구성 추천

2레이어 PCB 기준 추천 구조:

```text
Top Layer    : VBAT 구리영역
Bottom Layer : GND 구리영역
```

이 방식은 전원 분배용 PCB에서 단순하고 강력하다.

### 기본 배치 예시

```text
┌──────────────────────────────────┐
│ BATT IN                          │
│ [ + ][ - ]                       │
│                                  │
│ MOTOR OUT       [ + ][ - ]       │
│ 5V BUCK IN      [ + ][ - ]       │
│ 3V3 BUCK IN     [ + ][ - ]       │
│ SPARE OUT       [ + ][ - ]       │
│                                  │
│ TP_VBAT      TP_GND              │
└──────────────────────────────────┘
```

배터리 입력과 모터 출력은 가능하면 가깝게 둔다. 모터 쪽이 가장 큰 전류와 노이즈를 만들 가능성이 높기 때문이다.

## 6. 구리영역 설계 고려사항

### 구리영역 기본 원칙

- 얇은 트레이스를 길게 긋기보다 넓은 구리영역으로 연결한다.
- `VBAT`와 `GND`를 각각 충분히 넓게 깐다.
- 전류가 많이 흐르는 배터리 입력 → 모터 출력 경로는 짧고 넓게 만든다.
- 중간에 좁은 목이 생기지 않게 한다.

나쁜 예:

```text
넓은 구리영역 ── 좁은 통로 ── 넓은 구리영역
```

좋은 예:

```text
배터리 입력과 모터 출력이 넓은 면으로 바로 이어짐
```

### 보드 외곽 여유

구리영역은 보드 끝까지 바짝 깔지 않는다.

추천:

```text
보드 외곽에서 구리영역까지 0.5mm 이상
가능하면 1.0mm 이상
```

### Clearance 추천

7.4V 자체는 낮은 전압이지만, 배터리 쇼트 시 큰 전류가 흐를 수 있다.

추천값:

```text
최소 clearance: 0.5mm 이상
가능하면: 0.8mm ~ 1.0mm 이상
```

전원 분배 보드는 공간을 아끼는 것보다 안정성과 실수 방지가 더 중요하다.

### 마운팅 홀 주변

마운팅 홀 주변에는 구리영역을 깔지 않는 것을 추천한다.

```text
마운팅 홀 주변 keepout: 반경 2~3mm 이상 권장
```

금속 나사, 금속 스페이서, 흔들리는 금속 부품이 전원층과 접촉하는 것을 방지한다.

## 7. 솔더마스크와 쇼트 관련 주의

PCB 제작 시 대부분의 구리영역은 솔더마스크로 덮인다.

```text
초록색/검정색/파란색 PCB 표면 = 솔더마스크 절연층
은색/금색 패드 = 노출된 금속부
```

따라서 Top에 `VBAT`, Bottom에 `GND`를 깔아도 표면 전체가 그대로 금속으로 노출되는 것은 아니다.

하지만 아래 부분은 쇼트에 주의해야 한다.

- 커넥터 납땜 패드
- 테스트포인트
- 비아 또는 노출 패드
- 스크류 터미널의 금속 나사/클램프
- 마운팅 홀 주변 금속 나사
- 긁혀서 솔더마스크가 벗겨진 부분
- 납땜 후 남은 플럭스/납땜 찌꺼기

조립 후에는 눈으로 쇼트 가능성을 확인하고, 멀티미터 연속성 모드로 `VBAT`와 `GND`가 쇼트되지 않았는지 반드시 확인한다.

## 8. KiCad 작업 순서

### 1단계: 회로도 작성

필요한 커넥터와 보호소자를 배치한다.

```text
BATT_IN 2P
MOTOR_OUT 2P
BUCK_5V_IN 2P
BUCK_3V3_IN 2P
SPARE_OUT 2P
PTC / Fuse
Reverse Protection
Power LED + R
TP_VBAT / TP_GND
```

### 2단계: 네트 라벨 지정

`+` 라인은 모두 `VBAT`, `-` 라인은 모두 `GND`로 연결한다.

### 3단계: 풋프린트 지정

실제 구매할 부품의 치수를 보고 풋프린트를 고른다.

중요 확인 항목:

- 핀 간격
- 핀 구멍 크기
- 부품 외형 크기
- 커넥터 삽입 방향
- 터미널 나사 방향
- 보드 가장자리와 간섭 여부

### 4단계: PCB 외형 작성

`Edge.Cuts` 레이어에서 보드 외곽을 그린다.

전원 분배보드는 작게 만들어도 되지만, 너무 빽빽하게 만들 필요는 없다. 커넥터 조작과 나사 조임 공간을 생각한다.

### 5단계: 부품 배치

추천 배치 우선순위:

1. 배터리 입력 커넥터
2. 모터 출력 커넥터
3. 퓨즈/PTC
4. 5V/3.3V 컨버터 입력 커넥터
5. 예비 출력
6. LED, 테스트포인트
7. 마운팅 홀

### 6단계: 구리영역 추가

KiCad PCB 편집기에서:

```text
Add Filled Zone
Top Layer 선택
Net = VBAT
보드 외곽보다 약간 안쪽으로 영역 작성

Add Filled Zone
Bottom Layer 선택
Net = GND
보드 외곽보다 약간 안쪽으로 영역 작성

B 키로 Zone Fill
```

### 7단계: DRC 검사

반드시 디자인룰 검사를 돌린다.

확인할 것:

- `VBAT`와 `GND` 쇼트 없음
- clearance 오류 없음
- 미연결 net 없음
- 마운팅 홀 주변 구리 접촉 없음
- 커넥터 패드 주변 간격 충분

### 8단계: 실크 표시

전원 보드는 실크가 매우 중요하다.

크게 표시할 것:

```text
BATT IN
MOTOR
5V BUCK IN
3V3 BUCK IN
SPARE
+
-
VBAT
GND
```

`+`, `-` 표시는 커넥터마다 크게 넣는다. 실수 방지용으로 정말 중요하다.

## 9. 전류와 발열 고려

### 커넥터 정격

커넥터는 반드시 예상 전류보다 여유 있게 고른다.

대략적인 방향:

| 라인 | 전류 특성 | 커넥터 추천 |
|---|---|---|
| 배터리 입력 | 전체 전류가 지나감 | 가장 튼튼한 커넥터 |
| 모터 출력 | 순간전류 큼 | 배터리 입력과 동급 추천 |
| 5V 컨버터 입력 | 중간 전류 | 부하에 따라 결정 |
| 3.3V 컨버터 입력 | 비교적 작음 | 작은 커넥터도 가능 |

### 모터 라인

모터 라인은 순간적으로 큰 전류를 요구할 수 있으므로:

- 배터리 입력과 가까이 배치
- 구리영역 넓게
- 병목 없게
- 컨버터 입력 라인과 너무 복잡하게 얽히지 않게

### 캐패시터 위치

입력 벌크 캐패시터는 배터리 입력부 또는 모터/컨버터 분기 근처에 둔다.

```text
BATT_IN 근처: 470uF + 0.1uF
```

다만 모터 드라이버 모듈과 벅컨버터 모듈에도 자체 캐패시터가 있을 수 있으므로, 중복이 과하진 않은지 실제 모듈을 보고 판단한다.

---

## 10. 제작 전 체크리스트

Gerber 뽑기 전 확인:

- [ ] 모든 `+` 커넥터가 `VBAT`에 연결되어 있는가?
- [ ] 모든 `-` 커넥터가 `GND`에 연결되어 있는가?
- [ ] `VBAT`와 `GND`가 쇼트되어 있지 않은가?
- [ ] 배터리 입력과 모터 출력 경로가 짧고 넓은가?
- [ ] 구리영역이 보드 외곽에서 너무 가깝지 않은가?
- [ ] 마운팅 홀 주변에 구리가 제거되어 있는가?
- [ ] 커넥터 방향이 실제 배선하기 편한가?
- [ ] 스크류 터미널 나사 조이는 방향이 막히지 않는가?
- [ ] `+`, `-` 실크 표시가 모든 커넥터에 있는가?
- [ ] 전해 캐패시터 극성 표시가 명확한가?
- [ ] 테스트포인트가 충분히 떨어져 있는가?
- [ ] DRC 오류가 없는가?
- [ ] 3D Viewer에서 커넥터 간섭이 없는가?

---

## 11. 조립 후 체크리스트

처음 전원 넣기 전:

- [ ] 육안으로 납땜 브릿지 확인
- [ ] 멀티미터 연속성 모드로 `VBAT`와 `GND` 쇼트 확인
- [ ] 배터리 없이 각 커넥터의 `+`끼리 연결 확인
- [ ] 배터리 없이 각 커넥터의 `-`끼리 연결 확인
- [ ] 전원 공급 장치로 낮은 전류 제한을 걸고 첫 테스트
- [ ] 전원 LED 점등 확인
- [ ] 각 출력 커넥터에서 VBAT 전압 확인
- [ ] 모터 연결 전 5V/3.3V 컨버터 입력 전압 확인
- [ ] 모터 연결 후 발열, 전압강하, 리셋 여부 확인

첫 전원 인가 시에는 배터리 직결보다 DC 파워서플라이로 전류 제한을 걸고 테스트하는 것이 안전하다.

## 12. 추천 결론

이번 전원 분배 PCB는 다음 방향으로 설계하는 것을 추천한다.

```text
2 Layer PCB
Top Layer    = VBAT 구리영역
Bottom Layer = GND 구리영역

커넥터는 2P 스크류 터미널 5.08mm 위주로 통일
배터리 입력 직후 퓨즈/PTC
전원 LED + 저항
TP_VBAT / TP_GND
예비 출력 1개 추가
마운팅 홀 주변 keepout
실크로 + / - 크게 표시
```

만능기판에서 전원선을 일일이 분기하는 것보다 훨씬 깔끔하고, 이후 로버/보트 프로젝트에서도 반복해서 사용할 수 있는 좋은 기본 모듈이 될 것이다.
