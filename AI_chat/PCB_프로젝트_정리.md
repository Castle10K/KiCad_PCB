# PCB 설계 프로젝트 - 진행 정리

## 🎯 프로젝트 개요

**목표**: 멀티 모듈 통합 메인보드 (로버 로봇용) 직접 설계 및 제작

**핵심 모듈**:
- ESP32 UWB DW3000 (Makerfabs, v1.1) - 메인 컨트롤러 + UWB 통신
- BNO085 IMU - 방향각(yaw) 측정
- TAU1201 GNSS - GPS 위치 파악 (AllyStar)
- DRV8833 모터 드라이버 x2 - TT모터 4개 구동
- MP1584EN - 5V DC-DC 변환
- MINI360 - 3.3V DC-DC 변환

---

## ⚙️ 기본 설정

| 항목 | 선택 |
|---|---|
| EDA 툴 | **KiCad** (PCB 설계) + Fusion 360 (하우징) |
| PCB 제조 | JLCPCB 외주 |

| 레이어 | **2층** (TOP: 부품/신호/전원, BOTTOM: GND 플레인) |
| 부품 타입 | THT (관통 홀, 손납땜 친화적) |
| OS | Windows |
| 사용자 수준 | 회로도 초보 |

## 🔋 전원 설계

```
2S LiPo 배터리 (7.4V)
    │
    ├── BAT_IN1 (XT30 커넥터)
    │
    ├── FUSE1 (5A 퓨즈)
    │
    └── VBAT_F (보호된 전원)
        │
        ├── DRV8833 x2 (직결) → TT모터 x4
        ├── MP1584EN → 5V0 → ESP32 UWB
        └── MINI360  → VCC(3.3V) → BNO085 + TAU1201
```

### 전원 컨버터 사양
- **MP1584EN**: 각 측면 6핀 소켓, IN-OUT 간격 8 × 2.54 = **20.32mm**
- **MINI360**: 각 측면 4핀 소켓, IN-OUT 간격 6 × 2.54 = **15.24mm**
- **DRV8833**: IN-OUT 간격 6 × 2.54 = **15.24mm**

### 센서 통신
| 모듈 | 프로토콜 | 핀 |
|---|---|---|
| BNO085 IMU | UART | RX=IO32 (SDA), TX=IO33 (SCL), RST=IO5 |
| TAU1201 GNSS | UART | **TX→IO36** (변경 예정, IO16/17은 PSRAM 점유) |
| DW3000 UWB | SPI (내부) | SCK=18, MISO=19, MOSI=23, SS=4, RST=27, IRQ=34 |

### 주의사항
- **IO12 부트스트랩 핀**: 10kΩ 풀다운 저항(R1) 추가됨
- **IO15 부트스트랩 핀**: 10kΩ 풀다운 저항(R2) 추가됨
- **BNO085 UART 모드**: PS1 솔더점퍼로 설정 (모듈 자체)

## 📐 PCB 배치 전략

### 레이아웃
```
┌────────────────────────────────────┐
│ [전원부: BAT_IN, FUSE, C1, C2]    │ ← 좌측 상단
│ [MP1584EN] [MINI360]              │ ← 전원 변환기
├────────────────────────────────────┤
│       [J1 ───── ESP32 ───── J2]   │ ← 중앙
│   [J3 BNO085]    [J4 TAU1201]    │ ← ESP32 주변
│   [DRV_L]          [DRV_R]        │ ← 모터 드라이버
├────────────────────────────────────┤
│ [J11][J12]      [J13][J14]        │ ← 모터 터미널 (가장자리)
└────────────────────────────────────┘
```

### 배치 원칙
- **신호 경로 최단화**: ESP32 중앙 배치
- **IMU 기준 L/R 분리**: 좌/우 모터 드라이버 배치
- **전원/신호 분리**: 전원부는 한쪽으로
- **TAU1201 안테나**: 보드 가장자리 (외부 노출 필요)
- **디커플링 캐패시터**: 각 모듈 전원핀 바로 앞

### 모듈 클리어런스 (Courtyard 외 추가 고려)
- BNO085: 15.5mm 가로 공간
- TAU1201: 6mm 깊이 공간 (세로로 세워짐, 32×28×6mm)
- DRV8833: 15.24mm × 16mm

## 🛣️ 배선 (Routing)

### 트레이스 두께 설정
| 용도 | 두께 |
|---|---|
| 신호선 | 0.3mm |
| 전원선 | 1.0mm |
| 모터 전원 | 1.5mm |
| 최소 공간거리 | 0.2mm |

### 진행 상황
- ✅ **VBAT_F 배선 완료** (퓨즈 → C1, C2, DRV_L, DRV_R, MP1584EN_IN, MINI360_IN)
- ✅ **5V0 배선 완료** (MP1584EN_OUT → ESP32 J2 1번 핀)
- ✅ **VCC(3.3V) 배선 완료** (MINI360 → J3, J4, 디커플링 캐패시터들)
- ⏳ **GND 배선** - B.Cu 동박채우기로 일괄 처리 예정
- ⏳ **신호선 배선** - UART, SPI, PWM, RST 등

### 비아 사용법
- 배선 중 **V 키** → 비아 생성 + 레이어 전환
- F.Cu (빨강) ↔ B.Cu (파랑)

## 💡 배운 핵심 개념

### KiCad 워크플로우
```
회로도 (Schematic)  →  논리적 연결 정의
       ↓
풋프린트 할당      →  실제 부품 모양 지정
       ↓
PCB 업데이트       →  부품 PCB로 가져오기
       ↓
배치 (Placement)   →  부품 위치 잡기
       ↓
배선 (Routing)     →  실제 구리선 그리기
```

### 회로도 라벨 시스템
- **같은 이름의 라벨 = 자동 연결** (보이지 않는 선)
- 예: J1의 `IO12`와 DRV_L의 `IO12`는 자동 연결됨
- PWR_FLAG는 KiCad한테 "이건 전원이야!" 알려주는 마커

### 부트스트랩 핀
- ESP32 IO12: 플래시 전압 결정 (위험!)
- ESP32 IO15: 부트 메시지 (덜 위험)
- 해결책: 10kΩ 풀다운 저항으로 LOW 고정

### 디커플링 캐패시터
- 전해(큰 값) + 세라믹(작은 값) 짝꿍
- 위치 중요: **전원 → 캐패시터 → IC** 순서
- 각 IC 바로 옆에 100nF 세라믹 필수

### 직렬 vs 병렬 (PCB)
- 같은 네트(예: VBAT_F)로 연결된 부품 = **병렬**
- 트레이스가 어떻게 라우팅되든 전기적으로 동일
- 직렬: GND를 거쳐 다시 전원으로 돌아가는 경로
